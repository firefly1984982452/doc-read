# 阅读档案维护说明

网站首页由根目录 README.md 渲染；本目录记录维护流程，不进入公开书目和全文搜索。

## 本地启动

需要 Node.js 20 或更高版本。首次安装运行 `npm ci`，日常预览运行 `npm run dev`，浏览器打开 `http://127.0.0.1:3000/`。端口冲突时使用 `DOC_READ_PORT=3001 npm run dev`。

`npm run serve` 只提供 Docsify 静态预览；修改原文件的错别字接口由 `npm run dev` 提供。修正前的备份保存在 `.codex-backups/typos/`。不要将备份、环境变量文件提交到公开仓库。

## 新增与整理阅读笔记

1. 普通笔记放在 `docs/read/`；二十四史等章节笔记放在 `docs/read-history/` 对应子目录，文件名使用作者和书名。
2. 每篇保留一个一级标题，章节使用二级标题，章节内的子主题使用三级标题。调整标题层级时保留标题文字，检查目录跳转和折叠。
   新建笔记沿用“作者《书名》＋实际内容类型 | 问题式副标题”的标题格式；副标题结合书籍主题和阅读动机，不遗漏。
3. 标题后填写 `date: YYYY-MM-DD`，也兼容原有时间戳。仅能确认月份时使用 `date: YYYY-MM`；资料矛盾或无法确定时使用 `date: unknown`，并在紧随其后的 HTML 注释中写明 `日期依据：`。出版日期不能直接当作笔记日期。
4. 在 `docs/years/YYYY.md` 对应月份添加阅读记录，并在 `docs/library.md` 维护分类；同时在 `docs/think/update.md` 对应年月按更新日期倒序补充日志，沿用已有格式，区分新增笔记、在读框架和已完成内容。新增年份时沿用现有年度文件格式，核对月度及年度字数。
5. 图片替代文字写出书名及内容用途，例如“《百年孤独》人物关系图”。不能确认画面细节时按所在章节说明用途，不编造图中内容。
6. 校对报告放在 `reports/`，不要放入阅读笔记目录。`reports/` 默认忽略，确需长期保留的报告在 `.gitignore` 中按文件名列出例外。

### 阅读字数取整（用户明确，2026-09-21）

- 单本字数以“万字”为单位取整数：10万以下四舍五入；10万以上在整数部分基础上加1万。例如6.5万记为7万，9.8万记为10万，13.3万记为14万。
- 笔记书籍信息、年度归档条目使用同一个取整结果；月度、年度总字数按这些单本统计值相加。
- 取整针对原始字数，已有的整数统计结果不重复加1万。原始数值和来源可保留在 Markdown 注释中，便于核查。

`docs/catalog.md`、`assets/data/` 下的阅读数据和搜索索引、`sitemap.xml`、入口资源版本以及 `assets/vendor/` 均由生成脚本维护。不要手改这些输出。规则数据以 `scripts/lib/typo-rules.mjs` 等源码为准。

## 验证与发布

完成编辑后运行 `npm run build`。它依次生成数据、检查链接和元数据、运行单元测试、检查部署资源。检查输出不能代替实际浏览器操作。

运行 `npm run test:browser` 验证首页失败重试、搜索分片失败恢复、手机导航及文章复制。macOS 默认使用已安装的 Google Chrome；其他环境可运行 `npx playwright-core install chromium`，或者通过 `DOC_READ_TEST_BROWSER` 指定 Chromium/Chrome 可执行文件。测试启动独立本机端口与隔离浏览器，拦截站外请求并模拟剪贴板，不调用发布助手。

提交前查看 `git diff`，确认正文、年度数据及生成输出对应；再次执行 `npm run generate` 应不产生新的差异。提交内容文件时同时提交生成文件，否则线上搜索和书目可能仍然显示旧内容。

仓库的 `.github/workflows/quality.yml`负责质量检查，不能把检查成功等同于线上部署成功。推送后在仓库 Actions / Pages 中核对部署状态，并打开线上首页和一篇新笔记验证。当前本地优化不会自动提交、推送或发布。

## 多平台工具

公众号按钮复制当前文章的富文本。知乎按钮连接本地助手准备草稿，Shift 点击只复制；小红书按钮连接本地助手处理素材。使用这些功能前先阅读 `.env.example`，需要时运行 `npm run xhs:server`；`npm run xhs:install` 会安装常驻助手，`npm run xhs:status` 查询状态，`npm run xhs:uninstall` 卸载。

账号登录、草稿和正式发布应按实际操作需要分别处理。浏览器回归测试不操作真实账号。
