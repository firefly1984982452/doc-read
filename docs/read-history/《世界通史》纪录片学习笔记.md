# 《世界通史》100集纪录片学习笔记 | 从石器时代到万隆会议

date: 2026-11-23

按央视百集纪录片《世界历史》的播出顺序整理。节目从早期人类与农业讲起，经古代文明、跨洲交流和工业革命，最后讨论两次世界大战、冷战与亚非国家争取独立和主权的进程。

每集先列关键事件及其发生时间，再梳理背景和影响。阶段配图从左到右按时间排列，人物与场景为艺术化示意。远古及部分古代事件采用考古约数或传统纪年。
