## 三、每章情节梗概

### 情节阶段 01：航船上的世界冠军

在从纽约驶向布宜诺斯艾利斯的客轮上，“我”从一位熟人那里得知，国际象棋世界冠军岑托维奇也在船上。冠军的名声与冷淡举止引起“我”的好奇。“我”关注的不只是比赛成绩，还想理解一个把生活集中在棋盘上的人。

### 情节阶段 02：岑托维奇的成长与成名

叙述转向岑托维奇的往事。他是船夫之子，父亲去世后由乡村神父收养。神父试图教他读写和学习，但他在这些方面表现迟缓。一次偶然的下棋机会，却显出他的惊人棋艺。此后他接受训练、参加比赛，最终成为世界冠军。

### 情节阶段 03：付费邀战与第一次落败

“我”试着通过下棋引起冠军注意，认识了争胜心强的苏格兰商人麦克康纳。冠军愿意下棋，但要收费。麦克康纳承担费用，几位乘客共同商议走棋，与冠军较量。他们很快败下阵来，麦克康纳不甘心，要求再来一局。

### 情节阶段 04：陌生人的指点与和棋

在乘客与冠军的第二盘集体对局中，乘客准备走出一个看似有利的棋步。一位陌生乘客突然阻止他们，指出其中的陷阱，并提供后续应对。他的指导让众人抵住冠军的进攻，最后取得和棋。这个人就是B博士。

### 情节阶段 05：B博士讲述被捕与隔离

“我”与B博士交谈，了解到他来自奥地利，曾从事法律与财产管理工作，掌握教会和旧皇室相关财产的信息。纳粹控制奥地利后，盖世太保为了逼他交代这些信息，把他隔离关押在旅馆房间，反复审讯。

### 情节阶段 06：偷得棋谱，建立精神支点

一次等待审讯时，B博士从一件外套的口袋里偷到一本书，并把它带回房间。他原本期待得到文学作品，发现只是一本收录150盘大师对局的棋谱，一度失望。但在没有其他读物的环境中，他开始学习棋谱，用有限材料模拟棋盘和棋子，再逐渐在脑中复现棋局。

### 情节阶段 07：自我对弈与精神崩溃

当150盘棋局已被反复研习、熟记，B博士开始在脑中创造新的对局。他让自己同时成为执白与执黑的双方，努力使两边都争取胜利。没有外界生活调节的对弈逐渐失控：输的一方不断要求再战，他越来越亢奋、焦躁，最后出现严重的精神危机。

### 情节阶段 08：返回船上，只想检验一次

叙述回到船上。B博士说明，他不是以职业棋手身份来争夺冠军头衔，而想知道在囚禁中形成的棋艺，能否用于真实棋盘、真实棋子和真实对手。他同意与岑托维奇对局，同时提出只下一盘，试图控制风险。

### 情节阶段 09：首局获胜，打破停止的约定

B博士正式与冠军单独对局。他展现出出色的计算能力，赢下这一盘，让围观者吃惊。但冠军的缓慢落子令他不安。对手提出再下一盘时，他在兴奋中立刻答应，越过了自己“只下一盘”的边界。

### 情节阶段 10：再度失控，主动退出

第二盘独立对局中，岑托维奇有意放慢节奏。等待让B博士越来越烦躁，他反复踱步、口渴，脑中逐渐转向另一盘棋，最终把想象中的棋局与眼前棋盘混淆。“我”察觉危险，提醒他此前的经历，使他清醒过来。博士向众人致歉，结束对局，并表示以后不再下棋。

### 两条时间线

**小说叙述顺序**

航船相遇 → 冠军成长往事 → 乘客付费对局 → B博士指点和棋 → B博士自述囚禁与棋谱 → 返回船上 → 独立对局首局胜 → 次局失控并退出。

**B博士经历的实际顺序**

从事财产管理 → 被捕、隔离审讯 → 偷得棋谱 → 熟记150盘大师棋局 → 自我对弈 → 精神崩溃 → 治疗与获释 → 船上指导乘客 → 与冠军独立对局 → 退出。

### 三个值得回看的问题

1. **棋谱为何既能帮助，也会造成危机？** 它恢复了博士的精神活动，但当活动失去外界生活、休息与其他人际联系的调节时，自我对弈转成无法停止的争胜。两种效果发生在不同阶段。
2. **两名棋手的差别在哪里？** 冠军擅长实体棋盘上的职业竞技，博士的能力来自极端环境中的脑内训练。前者的冷静与后者的敏感形成叙事对照，但不能据此把冠军直接写成纳粹人员。
3. **退出能否算一种胜利？** 从竞技角度，他没有继续完成对局；从保护自我的角度，他停止了危险的重复。这是阅读解读，不是小说中另一项比赛结果。

## 四、书摘

> 我这一生一直对各种有偏执狂的人感兴趣——那种痴迷于单一思想的人，因为一个人给自己划定的界限愈多，他在某一方面就愈是接近于无限。

> 我从早到晚地期待发生点什么，可是什么都没有发生。我就这样一直等下去，还是什么都没有发生。我左等右等，左思右想，直至太阳穴发痛。什么都没有发生。我依然孤单一人。孤单一人。孤单一人。
