# 一键送到知乎草稿

运行 `npm install`，再运行 `npm run xhs:install` 更新共用的本地助手。`npm run xhs:status` 检查运行状态。

阅读笔记页面点击“知”按钮，助手使用项目固定版本的 chrome-devtools-mcp 连接日常 Chrome。在 Chrome 开启远程调试并允许连接，保持知乎登录。为防止其他网页调用本地助手偷传笔记，每次在 Chrome 确认“导入草稿”后才传入正文。

自动填入标题、副标题、正文和图片，开启目录，从 `~/Downloads/codex-图片生成/公众号图片` 按完整书名匹配 PNG/JPG 封面。多个候选会要求选择，找不到会明确提示；遇到裁剪窗口需要人工确认。只存草稿，绝不点击发布。可按住 Shift 点击“知”继续使用原来的富文本复制。

支持本机 file://（script 回调）与 HTTP（Fetch）。原 Markdown 不会修改。重复导入相同笔记会打开已完成草稿而不覆盖用户编辑；内容发生变化时创建新的草稿。记录保存在 `~/Library/Application Support/doc-read/zhihu-drafts.json`。任务中途失败会保留已经创建的草稿；再次导入可继续补目录和封面，不重写正文。

页面显示进度和可操作的错误。知乎页面结构变化、图片转存失败、登录失效或授权超时都会停止，不会尝试发布。Chrome 安装就绪不等于知乎已登录或调试连接已授权。
